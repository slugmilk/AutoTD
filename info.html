텍스트 프롬프트를 터치디자이너
미디어아트로 자동 변환

AutoTD는 AI 오케스트레이션과 TouchDesigner를 실시간으로 결합하는 미디어아트 생성 플랫폼입니다. 사용자의 직관적인 텍스트 입력을 바탕으로 복잡한 파라미터를 분석하고, 검증된 TouchDesigner 템플릿 노드 체인을 조화롭게 구성하여 비주얼을 실시간 렌더링합니다.

핵심 기술 개념

AutoTD가 AI와 미디어아트를 연결하기 위해 구현한 세 가지 주요 기능 레이어

LLM 파라미터 매핑 & 튜닝

Ollama 및 Gemini 아키텍처를 기반으로 작성된 LLM 라우터가 입력된 텍스트의 무드, 강도, 속도, 노이즈 값을 다차원 벡터로 분석합니다. 이를 매핑 스키마(TDParameters)로 가공하여 터치디자이너에서 실제 변수로 직접 연동할 수 있는 뼈대를 만듭니다.

사전 검증된 Recipe 매핑

제한 없는 LLM의 임의 노드 생성이 주는 불안정성을 막기 위해, 시스템은 검증된 3대 레시피(Particle, Glitch, 3D Orb) 구조를 하드코딩된 노드 체인으로 갖추고 있습니다. AI는 프롬프트 무드에 가장 알맞은 레시피를 매핑 및 활성화합니다.

TouchDesigner MCP Server

FastAPI 백엔드 서버와 터치디자이너 내부의 Web Server DAT(포트 9980) 간에 커스텀 MCP 연결을 수립합니다. 실시간 렌더링된 render TOP 미리보기 데이터, GLB/OBJ의 실시간 파싱 바운딩 박스 상태, 그리고 텍스처 composite 연결 검증 텔레메트리를 주고받습니다.

시스템 파이프라인 아키텍처

프론트엔드 입력부터 터치디자이너 실시간 렌더링까지 이어지는 데이터 흐름

1

사용자 프롬프트 입력 (Web UI)

원하는 분위기(예: "우주 속을 유영하는 몽환적인 파란색 입자")를 입력하고 생성 요청을 보냅니다.

↓
2

LLM 분석 및 구조화 (FastAPI / Ollama)

LLM Router가 프롬프트를 분석하여 Recipe ID와 파라미터 값(속도, 밝기, 색상 모드, 노이즈)을 JSON 형식으로 추출합니다.

↓
3

외부 에셋 생성 연동 (ComfyUI / Trellis) [실험단계]

외부 이미지(ComfyUI) 및 3D 메시(Trellis GLB)를 생성하고 텍스처를 obj/fbx 형식으로 파싱해 TouchDesigner 호환용 에셋으로 준비합니다.

↓
4

TouchDesigner Node Apply (MCP Server)

Web Server DAT 통신을 통해 터치디자이너 내부에 파라미터를 인젝션하고, 해당 레시피의 노드 구조(SOP/POP/TOP)를 실시간 업데이트합니다.

↓
5

비주얼 피드백 및 렌더링 텔레메트리 반환

터치디자이너 내부의 해상도 검증, geometry의 point/primitive 계산 로그와 최종 결과물 TOP 렌더링 이미지를 실시간으로 웹 스크린에 반영합니다.

비주얼 레시피 프로필

터치디자이너와 연계되는 세 가지 템플릿의 비주얼 특징과 전송되는 파라미터 설정

Particle Template

Dreamy Particle Field

부드럽게 흘러가는 입자와 신비로운 분위기를 연출하기 위한 레시피입니다. 자연, 우주, 꿈, 몽환적 정원 등의 콘셉트에 추천됩니다. POP(입자)와 피드백 TOP을 결합해 긴 잔상이 남는 시각 스타일을 제공합니다.

Particle Density
0.7 ~ 1.0 (최대)
Noise Strength
0.3 ~ 0.5 (부드러운 기류)
Motion Speed
0.2 ~ 0.4 (느긋하게)
Glow Value
0.8 (강한 아우라)
Feedback Template

Glitch Feedback Field

격렬한 피드백 루프와 디지털 왜곡 현상(글리치)을 동반한 테크니컬 스타일입니다. 사이버펑크, 네온, 카오스, 일렉트로닉 비주얼 등의 다이내믹한 텍스트에 매핑됩니다.

Feedback Opacity
0.92 ~ 0.97 (긴 잔상)
Noise Strength
0.8 ~ 1.0 (강렬한 난류)
Motion Speed
0.7 ~ 0.9 (빠른 변화)
Color Preset
Neon / Cool (강렬한 대비)
3D Geometry Template

Soft 3D Orb

회전하는 3D 지오메트리 조형과 조명, 은은한 기하학적 배치를 사용하는 조각상 및 오브제 스타일입니다. 미니멀, 조각, 3D 구체, 가상 건축 등의 미학을 구현합니다.

Geometry Bounds
Auto Normalize (원점 고정)
Rotation Speed
0.3 ~ 0.5 (일정한 회전)
Light Strength
0.6 (부드러운 음영)
File Type
OBJ / GLB (자동 변환 지원)

GitHub Repository 및 설치 안내

이 프로젝트는 오픈 소스로 개발되고 있습니다. 로컬 환경에서 클론하여 손쉽게 실행해 보세요.

git clone https://github.com/slugmilk/AutoTD.git

1. 가상환경 및 의존성 설치:

pip install -r requirements.txt

2. 백엔드 및 클라이언트 웹 서버 실행:

python server.py

3. 터치디자이너 연동:

프로젝트 디렉터리에 포함된 AutoTD_MCP.toe 파일을 실행하면, 포트 9980에서 웹 소켓 클라이언트가 수신 대기 상태가 됩니다.
