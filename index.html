Project Overview

Generate TouchDesigner-based
media art from text prompts.

AutoTD Web은 사용자가 텍스트로 미디어아트 아이디어를 입력하면, 생성형 AI 에이전트가 이를 해석해 TouchDesigner 기반 결과물로 변환하는 웹 플랫폼입니다.

TouchDesigner는 강력한 미디어아트 제작 도구지만 노드 구조 이해, 파라미터 조정, 렌더링 흐름 파악 등 초보자에게 높은 학습 장벽이 있습니다. AutoTD Web은 이 과정을 웹 인터페이스와 AI 에이전트로 단순화합니다.

목표는 사용자의 텍스트 아이디어를 사전 구축된 TouchDesigner 템플릿과 연결해 빠르게 시각 결과로 확인할 수 있는 제작 흐름을 제안하는 것입니다.

Why AutoTD Web?

비전공자와 전공자 모두
더 빠르고 직관적으로

AutoTD Web은 기존 미디어아트 생성 파이프라인의 한계를 보완해, 비전공자에게는 복잡한 기술 지식 없이 제작을 경험할 수 있는 환경을 제공하고, 전공자에게는 반복적인 초기 세팅 시간을 줄여주는 중간 도구 역할을 목표로 합니다.

사용자는 템플릿을 선택하고 프롬프트를 입력합니다. 에이전트는 목표를 분석하고, 필요한 이미지 또는 3D 소스를 생성하거나 선택한 뒤 TouchDesigner MCP Server와 연결해 최종 미디어아트 결과물로 변환합니다.

이를 통해 복잡한 노드 구조를 직접 다루지 않아도 창작 아이디어를 빠르게 실험하고 발전시킬 수 있습니다.

01

비전공자

텍스트 입력만으로 고품질 미디어아트를 직관적으로 제작하고 경험할 수 있는 새로운 접근 방식을 제공합니다.

02

전공자

초기 프로토타입과 반복적인 수정 시간을 줄여주는 효율적인 보조 도구로 활용할 수 있습니다.

03

기술적 의의

생성형 AI와 TouchDesigner 워크플로를 유기적으로 연결해 실제 미디어아트 제작 파이프라인으로 확장합니다.

Technology & Implementation

프론트엔드, AI 에이전트,
TouchDesigner 실행 환경의 통합.

AutoTD Web은 프론트엔드, AI 에이전트, TouchDesigner 실행 환경, 결과물 출력 모듈로 구성된 구조를 가집니다.

프론트엔드는 사용자의 템플릿 선택, 텍스트 입력, 생성 요청, 상태 확인, 결과 미리보기를 담당하고, 백엔드는 요청을 받아 전체 생성 흐름을 오케스트레이션합니다.

AI 에이전트는 사용자의 프롬프트를 분석해 스타일, 움직임, 색감, 출력 형식 등의 파라미터를 구조화하고 TouchDesigner 템플릿에 전달 가능한 형태로 정리합니다.

이후 TouchDesigner MCP Server를 통해 템플릿 기반 네트워크를 실행하고, 최종 결과를 TOX 및 MP4 파일로 출력합니다.

궁극적으로는 창작 발상과 기술 구현 사이의 간격을 좁히고, 더 많은 사용자가 미디어아트 창작에 접근할 수 있는 실험적 생태계를 조성하는 데 기여하고자 합니다.
