파라미터 매핑

TouchDesigner에서 돌려준 현재 파라미터를 확인합니다.

{
  "template_type": "waiting",
  "mood": "calm",
  "palette": "ember",
  "motion_speed": "medium",
  "effect_density": "medium",
  "duration": 24
}

미리보기 자리

TD가 `previewText`, `previewUrl`, `videoUrl`, `imageUrl` 중 하나를 보내면 여기서 표시합니다.

연결 전

TouchDesigner에서 미리보기 데이터를 보내기 전까지는 요약 텍스트가 표시됩니다.
