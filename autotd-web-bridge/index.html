생성 요청

프롬프트와 기본 파라미터, 그리고 사용할 템플릿을 직접 선택해서 TouchDesigner로 보냅니다.

선택한 템플릿이 그대로 TouchDesigner에 전달됩니다. 이제 템플릿 자동 추정은 하지 않습니다.

연결

TouchDesigner Web Server DAT와 WebSocket으로 통신합니다.

파라미터 매핑

TouchDesigner가 받은 현재 파라미터를 확인합니다.

{
  "template_type": "particle_field",
  "mood": "calm",
  "palette": "ember",
  "motion_speed": "medium",
  "effect_density": "medium",
  "duration": 24
}

미리보기

TouchDesigner가 previewText, previewUrl, videoUrl, imageUrl 중 하나를 보내면 여기에 표시합니다.

연결 대기

TouchDesigner가 미리보기 데이터를 보내기 전까지는 요약 텍스트가 표시됩니다.

이벤트 로그

브라우저와 TouchDesigner 사이의 송수신 메시지를 추적합니다.
